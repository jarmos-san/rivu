---
title: Nuxt and Nitro route
description: Serve an RSS feed from a Nitro server route in a Nuxt app.
---

Nuxt runs on Nitro, so a file in `server/routes/` can serve `/rss.xml` directly.
This guide builds that route.

## The route

Create `server/routes/rss.xml.get.ts`:

```ts
import { eventHandler, setHeader } from "h3";
import { Feed } from "rivu";

const SITE_URL = "https://example.com";

export default eventHandler((event) => {
  const feed = new Feed(
    {
      title: "Example Blog",
      link: SITE_URL,
      description: "Notes on building things.",
      language: "en-US",
      items: [
        {
          title: "Hello, world",
          link: `${SITE_URL}/posts/hello-world`,
          description: "<p>The first post.</p>",
          guid: `${SITE_URL}/posts/hello-world`,
          pubDate: new Date("2025-10-10T08:00:00Z"),
        },
      ],
    },
    { feedURL: `${SITE_URL}/rss.xml` },
  );

  setHeader(event, "Content-Type", "application/rss+xml; charset=utf-8");

  return feed.generate();
});
```

Import `eventHandler` and `setHeader` from `h3`. The `.get.ts` suffix limits the
route to GET requests.

Nitro serves a returned string as-is, so the `Content-Type` header you set is
what clients see. Without it, Nitro would send the string as `text/html`.

## Using real content

Replace the hard-coded item with your own data. With Nuxt Content, for example:

```ts
import { queryCollection } from "@nuxt/content/server";
import { eventHandler, setHeader } from "h3";
import { Feed } from "rivu";

const SITE_URL = "https://example.com";

export default eventHandler(async (event) => {
  const posts = await queryCollection(event, "blog")
    .order("date", "DESC")
    .all();

  const feed = new Feed(
    {
      title: "Example Blog",
      link: SITE_URL,
      description: "Notes on building things.",
      items: posts.map((post) => ({
        title: post.title,
        link: `${SITE_URL}${post.path}`,
        description: post.description,
        guid: `${SITE_URL}${post.path}`,
        pubDate: new Date(post.date),
      })),
    },
    { feedURL: `${SITE_URL}/rss.xml` },
  );

  setHeader(event, "Content-Type", "application/rss+xml; charset=utf-8");

  return feed.generate();
});
```

The collection name and field names depend on your own content schema. Check
that every `date` parses to a valid `Date`, because an invalid one is written as
`Invalid Date`. See [troubleshooting](/docs/troubleshooting).

## Static sites

If you deploy with `nuxt generate`, tell Nitro to prerender the route so the
file exists in the output:

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  nitro: {
    prerender: {
      routes: ["/rss.xml"],
    },
  },
});
```

Static hosts choose the `Content-Type` from the file extension, so `.xml` is
served as an XML type.
