---
title: Styling with XSL
description: Make your feed readable in a browser with an XSL or CSS stylesheet.
---

Browsers show raw XML for an RSS URL, which is hard to read. The `stylesheet`
option adds a processing instruction that tells the browser how to render the
feed. Feed readers ignore it.

## Add the stylesheet

```ts
import { Feed } from "rivu";

const feed = new Feed(
  {
    title: "Example Blog",
    link: "https://example.com",
    description: "Notes on building things.",
    items: [],
  },
  {
    feedURL: "https://example.com/rss.xml",
    stylesheet: new URL("https://example.com/rss.xsl"),
  },
);
```

The output starts with:

```xml
<?xml version="1.0"?>
<?xml-stylesheet type="text/xsl" href="https://example.com/rss.xsl"?>
```

`stylesheet` takes a `URL` object. A URL whose path ends in `.css` is typed
`text/css`. Anything else is typed `text/xsl`.

## A minimal XSL file

Save this as `rss.xsl` and serve it from the URL you passed:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<xsl:stylesheet version="1.0" xmlns:xsl="http://www.w3.org/1999/XSL/Transform">
  <xsl:output method="html" encoding="UTF-8" />
  <xsl:template match="/">
    <html>
      <head>
        <title><xsl:value-of select="rss/channel/title" /></title>
      </head>
      <body>
        <h1><xsl:value-of select="rss/channel/title" /></h1>
        <p><xsl:value-of select="rss/channel/description" /></p>
        <ul>
          <xsl:for-each select="rss/channel/item">
            <li>
              <a href="{link}"><xsl:value-of select="title" /></a>
            </li>
          </xsl:for-each>
        </ul>
      </body>
    </html>
  </xsl:template>
</xsl:stylesheet>
```

## Things to watch

- Browsers apply a stylesheet only if it comes from the same origin as the feed.
  Host it on the same domain.
- Item descriptions are CDATA with HTML inside. In XSL, use
  `disable-output-escaping="yes"` on `xsl:value-of` if you want that HTML
  rendered. Browser support for it varies, so test in the browsers you care
  about.
- A CSS stylesheet works the same way. Pass a URL ending in `.css` and rivu
  writes `type="text/css"`.
