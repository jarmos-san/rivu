rivu builds an RSS 2.0 document from a plain object and returns it as a string.
It has one runtime dependency,
[xmlbuilder2](https://oozcitak.github.io/xmlbuilder2/), and needs no
configuration.

## Install

Use your package manager of choice.

```bash
pnpm add rivu
```

```bash
npm install rivu
```

```bash
yarn add rivu
```

```bash
bun add rivu
```

rivu is an ES module. `Feed` is a named export; there is no default export.

```ts
import { Feed } from "rivu";
```

## Minimal example

A feed needs a `title`, a `link`, a `description` and an `items` array.

```ts
import { Feed } from "rivu";

const feed = new Feed({
  title: "My Blog",
  link: "https://example.com",
  description: "Latest updates",
  items: [{ title: "Hello", link: "https://example.com/hello" }],
});

console.log(feed.generate());
```

```xml
<?xml version="1.0"?>
<rss version="2.0" xmlns:atom="http://www.w3.org/2005/Atom">
  <channel>
    <title><![CDATA[My Blog]]></title>
    <link>https://example.com</link>
    <description><![CDATA[Latest updates]]></description>
    <item>
      <title><![CDATA[Hello]]></title>
      <link>https://example.com/hello</link>
    </item>
  </channel>
</rss>
```

## Full example

This example sets optional channel fields, a complete item, a self link and a
stylesheet.

```ts
import { Feed } from "rivu";

const feed = new Feed(
  {
    title: "Example Blog",
    link: "https://example.com",
    description: "Notes on building things.",
    language: "en-US",
    lastBuildDate: new Date("2025-10-12T09:30:00Z"),
    items: [
      {
        title: "Hello, world",
        link: "https://example.com/posts/hello-world",
        description: "<p>The first post.</p>",
        author: "jane@example.com (Jane Doe)",
        category: ["intro", "meta"],
        guid: "https://example.com/posts/hello-world",
        pubDate: new Date("2025-10-10T08:00:00Z"),
      },
    ],
  },
  {
    feedURL: "https://example.com/rss.xml",
    stylesheet: new URL("https://example.com/rss.xsl"),
  },
);

console.log(feed.generate());
```

The output:

```xml
<?xml version="1.0"?>
<?xml-stylesheet type="text/xsl" href="https://example.com/rss.xsl"?>
<rss version="2.0" xmlns:atom="http://www.w3.org/2005/Atom">
  <channel>
    <atom:link href="https://example.com/rss.xml" rel="self" type="application/rss+xml"/>
    <title><![CDATA[Example Blog]]></title>
    <link>https://example.com</link>
    <description><![CDATA[Notes on building things.]]></description>
    <language>en-US</language>
    <lastBuildDate>Sun, 12 Oct 2025 09:30:00 GMT</lastBuildDate>
    <item>
      <title><![CDATA[Hello, world]]></title>
      <link>https://example.com/posts/hello-world</link>
      <description><![CDATA[<p>The first post.</p>]]></description>
      <author>jane@example.com (Jane Doe)</author>
      <category>intro</category>
      <category>meta</category>
      <guid isPermaLink="true">https://example.com/posts/hello-world</guid>
      <pubDate>Fri, 10 Oct 2025 08:00:00 GMT</pubDate>
    </item>
  </channel>
</rss>
```

A few things to notice:

- `title` and `description` are always wrapped in CDATA.
- `Date` values become RFC 822 strings.
- The `guid` is marked `isPermaLink="true"` because it is an http(s) URL.
- Each entry in a `category` array becomes its own element.
- Fields you leave out are omitted, not emitted empty.
