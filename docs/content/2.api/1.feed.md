`Feed` is the only runtime export. It holds the channel data and options you
pass in and serializes them when you call `generate()`.

```ts
import { Feed } from "rivu";
import type { ChannelElements, FeedOptions, Days, Hour, RSS } from "rivu";
```

The package also exports the types `ChannelElements`, `FeedOptions`, `Days`,
`Hour` and `RSS`.

## Constructor

```ts
new Feed(channelElements: ChannelElements, options?: FeedOptions)
```

| Parameter         | Type              | Required | Description                                                                                 |
| ----------------- | ----------------- | -------- | ------------------------------------------------------------------------------------------- |
| `channelElements` | `ChannelElements` | Yes      | Channel metadata and the `items` array. See [channel elements](/docs/api/channel-elements). |
| `options`         | `FeedOptions`     | No       | Document-level settings. See [feed options](/docs/api/feed-options).                        |

The constructor stores both arguments as given. It does not validate them.

## generate()

```ts
feed.generate(): string
```

Returns the feed as a pretty-printed XML string. The string starts with
`<?xml version="1.0"?>` and the root element is:

```xml
<rss version="2.0" xmlns:atom="http://www.w3.org/2005/Atom">
```

If you pass `stylesheet`, the `<?xml-stylesheet?>` instruction comes right after
the XML declaration. If you pass `feedURL`, an `<atom:link rel="self">` element
is the first child of `<channel>`. After that, channel fields are written in the
order RSS 2.0 lists them, followed by the items.

`generate()` has no side effects. You can call it more than once on the same
instance.

### How values are written

- `title` and `description` are always wrapped in CDATA.
- Any other string that contains markup is wrapped in CDATA automatically.
  Everything else is escaped as plain text.
- `Date` fields are written with `toUTCString()`, which is RFC 822 format.
- `undefined` and `null` fields are omitted.
- Array values, such as `category`, produce one element per entry.
- `guid` gets `isPermaLink="true"` when the value is an http(s) URL, and
  `"false"` otherwise.

## The RSS type

`Feed` implements the `RSS` interface, which has a single member:

```ts
interface RSS {
  generate: () => string;
}
```

Use it when you want to depend on the shape instead of the class.
