---
title: Item elements
description: Every field accepted on a feed item, with its type and RSS element.
---

Each entry in `items` becomes one `<item>`. All fields are optional, but RSS 2.0
expects an item to have at least a `title` or a `description`.

| Field         | Type                 | RSS element     | Notes                                                                    |
| ------------- | -------------------- | --------------- | ------------------------------------------------------------------------ |
| `title`       | `string`             | `<title>`       | Always CDATA.                                                            |
| `link`        | `string \| URL`      | `<link>`        | The URL of the full content.                                             |
| `description` | `string`             | `<description>` | Always CDATA. HTML is fine here.                                         |
| `author`      | `string`             | `<author>`      | RSS expects an email address, optionally as `email (Name)`.              |
| `category`    | `string \| string[]` | `<category>`    | One element per array entry.                                             |
| `comments`    | `string \| URL`      | `<comments>`    | URL of the comments page for the item.                                   |
| `guid`        | `string`             | `<guid>`        | Gets `isPermaLink="true"` for http(s) URLs, `"false"` for anything else. |
| `pubDate`     | `Date`               | `<pubDate>`     | Written as RFC 822.                                                      |

`title`, `link`, `description`, `author`, `comments` and `guid` can also be
`null`, which omits the element.

## guid

Use a stable value. Readers use the `guid` to decide whether they have seen an
item before.

```ts
{
  guid: "https://example.com/posts/hello-world";
}
```

```xml
<guid isPermaLink="true">https://example.com/posts/hello-world</guid>
```

A value that is not an http(s) URL is marked as not permanent:

```ts
{
  guid: "post-42";
}
```

```xml
<guid isPermaLink="false">post-42</guid>
```

## Markup in fields

`title` and `description` are always CDATA, so you can put HTML in them. For
other string fields, rivu checks for markup and switches to CDATA when it finds
some. Plain text is escaped.

## Not supported

The `enclosure` and `source` item elements are not implemented.
