---
title: Feed options
description:
  The optional second argument to Feed, covering the stylesheet and self link.
---

`FeedOptions` holds settings that apply to the whole document and are not part
of the RSS 2.0 channel definition. Pass it as the second argument to `Feed`.

| Option       | Type            | Output                                                  |
| ------------ | --------------- | ------------------------------------------------------- |
| `stylesheet` | `URL`           | An `<?xml-stylesheet?>` processing instruction.         |
| `feedURL`    | `string \| URL` | An `<atom:link rel="self">` element inside `<channel>`. |

## stylesheet

```ts
new Feed(channel, { stylesheet: new URL("https://example.com/rss.xsl") });
```

```xml
<?xml-stylesheet type="text/xsl" href="https://example.com/rss.xsl"?>
```

The `type` is chosen from the URL path. A path ending in `.css` produces
`text/css`. Anything else produces `text/xsl`. The value must be a `URL` object,
not a string.

See [styling with XSL](/docs/guides/styling-with-xsl) for a working stylesheet.

## feedURL

```ts
new Feed(channel, { feedURL: "https://example.com/rss.xml" });
```

```xml
<atom:link href="https://example.com/rss.xml" rel="self" type="application/rss+xml"/>
```

Set this to the public URL the feed is served from. The `atom` namespace is
declared on the root element in every feed, so the element is valid whenever it
appears.

Without `feedURL`, no self link is written. Validators report that as a
recommendation. See [validating your feed](/docs/guides/validating-your-feed).
