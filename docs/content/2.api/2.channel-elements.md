title: Channel elements
description:
  Every field accepted in the first argument of Feed, with its type and RSS
  element.
---

`ChannelElements` describes the `<channel>` of the feed. `title`, `link`,
`description` and `items` are required. Everything else is optional.

| Field            | Type                                           | RSS element        | Notes                                                                                                                               |
| ---------------- | ---------------------------------------------- | ------------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| `title`          | `string`                                       | `<title>`          | Required. Always CDATA.                                                                                                             |
| `link`           | `string`                                       | `<link>`           | Required. The URL of the site the feed describes.                                                                                   |
| `description`    | `string`                                       | `<description>`    | Required. Always CDATA.                                                                                                             |
| `items`          | `ItemElements[]`                               | `<item>`           | Required. One `<item>` per entry. See [item elements](/docs/api/item-elements).                                                     |
| `language`       | `string`                                       | `<language>`       | An IETF language tag such as `en-US`.                                                                                               |
| `copyright`      | `string`                                       | `<copyright>`      | Copyright notice.                                                                                                                   |
| `managingEditor` | `string`                                       | `<managingEditor>` | Email address of the editorial contact.                                                                                             |
| `webMaster`      | `string`                                       | `<webMaster>`      | Email address of the technical contact.                                                                                             |
| `pubDate`        | `Date`                                         | `<pubDate>`        | Written as RFC 822.                                                                                                                 |
| `lastBuildDate`  | `Date`                                         | `<lastBuildDate>`  | Written as RFC 822.                                                                                                                 |
| `category`       | `string \| string[]`                           | `<category>`       | One element per array entry.                                                                                                        |
| `generator`      | `string`                                       | `<generator>`      | Name of the software that produced the feed.                                                                                        |
| `docs`           | `"https://www.rssboard.org/rss-specification"` | `<docs>`           | Only this exact URL is accepted by the type.                                                                                        |
| `ttl`            | `number`                                       | `<ttl>`            | Minutes a client may cache the feed.                                                                                                |
| `image`          | `URL \| string`                                | `<image>`          | Not yet serialized to the nested form RSS 2.0 requires. See [troubleshooting](/docs/troubleshooting).                               |
| `textInput`      | `TextInput`                                    | `<textInput>`      | Accepted by the type but not yet serialized. See [troubleshooting](/docs/troubleshooting).                                          |
| `skipHours`      | `Hour`                                         | `<skipHours>`      | A single hour from 0 to 23. Not yet serialized to the nested form. See [troubleshooting](/docs/troubleshooting).                    |
| `skipDays`       | `Days`                                         | `<skipDays>`       | A single day name, `"Sunday"` to `"Saturday"`. Not yet serialized to the nested form. See [troubleshooting](/docs/troubleshooting). |

All optional fields can also be `null`, which has the same effect as leaving
them out.

## Dates

Pass `Date` objects. rivu does not parse strings.

```ts
const channel = {
  title: "Example",
  link: "https://example.com",
  description: "Example feed",
  pubDate: new Date("2025-10-10T08:00:00Z"),
  items: [],
};
```

This produces `<pubDate>Fri, 10 Oct 2025 08:00:00 GMT</pubDate>`.

## Categories

A single string produces one element. An array produces one element per entry.

```ts
category: ["engineering", "typescript"];
```

```xml
<category>engineering</category>
<category>typescript</category>
```
